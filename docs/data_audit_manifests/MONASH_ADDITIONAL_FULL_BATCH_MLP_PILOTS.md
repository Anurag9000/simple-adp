# Additional Monash full-batch MLP task screens (2026-10-24)

This addendum covers ten individual variants beyond the original 23-task pilot. Nine trained the repository `TabularMLP`; one (NN5 Daily with missing values) had no complete train/validation/test windows after dropping windows containing missing inputs or targets. Every trained task used the full training partition as one batch, Adam 1e-3, MSE, 30 epochs, best validation checkpoint, and one test evaluation. Lookback/horizon, split counts, per-model metrics, baselines, and CUDA memory below are taken from the companion JSON. Missing-value windows are omitted rather than imputing targets.
