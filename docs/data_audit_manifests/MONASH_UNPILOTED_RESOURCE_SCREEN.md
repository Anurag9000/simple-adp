# Monash parsed variants crossed out by full-batch resource screen (2026-10-24)

This screen accounts individually for parsed variants not admitted by an empirical pilot. It uses exact TSF totals/series counts and explicit fixed-length task profiles. For each series, the number of training windows is `max(0, length-L-2H+1)`, so `max(0, total_values - series_count*(L+2H-1))` is a conservative lower bound. The `[512]*5` hidden-activation storage is `windows × 5 × 512 × 4 bytes`; it excludes inputs, targets, gradients, parameters, optimizer state, validation tensors and CUDA workspace. Missing observations can be imputed using training-only statistics for this memory proof, so they do not reduce the number of possible examples. A lower bound above the 6 GiB device capacity is decisive. A smaller single-series task is crossed out for independent-group support.
