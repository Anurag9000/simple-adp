# Monash candidate full-batch MLP forecast pilots (2026-10-24)

**Pilot scope:** 23 of the 58 Monash variants with successful full archive downloads received this exact task screen. Task horizons are the repository’s documented prediction lengths. For each series, the last H observations are test, the preceding H are validation, and all length-L to horizon-H windows before validation train the global MLP. One full batch contains every training window. Values are normalized per series using only data before validation. Models use the repo `TabularMLP`, Adam 1e-3, MSE, 30 epochs, best validation checkpoint, one seed per architecture, and test once. The test metric is macro per-series RMSE/MAE normalized by the series training-prefix standard deviation. Seasonal naive uses the documented frequency where the lookback covers it.

This is an empirical screening pass, not a full architecture grid, repeated-seed estimate, ADP result, or runner-integrated experiment. A keep is provisional and requires later replication. Crossed candidates failed a baseline/skill check, the full-batch memory profile, or independent-series support.
